# One-Person Company Toolkit | 一人公司工具箱

> A public, evolving record of the tools, projects, and skills used while building a one-person company.
>
> 记录一个人从构想到经营公司的过程中，在不同阶段、不同工作场景里实际用过的工具、项目和 skill。

This repository is a field log, not a ranking or endorsement list. Each entry should explain the work being done, the stage of the journey, what was used, and what happened. The goal is to make real workflows easier to revisit and useful to other solo founders.

这里记录真实使用经历，不做工具排行榜或背书。每条记录尽量说明当时处于什么阶段、要完成什么工作、用了什么，以及结果如何，方便自己复盘，也给其他一人公司创业者提供参考。

Need another area? Create a folder with a short English name and add a bilingual `README.md` describing its scope. Keep entries in the relevant area rather than copying tool content into this repository.

需要新场景时，可以按需新建简短英文目录，并添加中英双语 `README.md` 说明范围。记录放在对应场景目录中；不要把工具或项目本身的内容复制进来。

## Add a record | 添加记录

1. Copy [`templates/usage-record.md`](./templates/usage-record.md) into the relevant area.
2. Name the file `YYYY-MM-DD-short-topic.md`, using the date of the work or tool use.
3. Fill in the stage, task, external links, workflow, and outcome. Be candid about limitations; a tool does not need to have worked well to be worth recording.

1. 复制 [`templates/usage-record.md`](./templates/usage-record.md) 到对应场景目录。
2. 文件名使用 `YYYY-MM-DD-简短主题.md`，日期填写实际工作或使用工具的日期。
3. 记录阶段、任务、外部链接、使用过程和结果。即使工具效果不理想，也可以如实记录。

Link to official sites, source repositories, or skill pages. Do not download or vendor tools, models, projects, skills, or other third-party assets here. Confirm that any linked material is appropriate to share publicly.

请链接到官方网站、源代码仓库或 skill 页面，不要在本仓库下载或收录工具、模型、项目、skill 等第三方内容。添加链接前确认相关信息适合公开分享。

## Public notes | 公开记录注意事项

This repository is intended to be public. Do not commit API keys, passwords, private personal information, confidential customer details, unpublished business plans, or anything you do not have the right to share. Review each record and its links before publishing.

本仓库面向公开分享。不要提交 API 密钥、密码、私人信息、客户机密、未公开的商业计划，或任何你无权公开的内容。发布前请检查记录正文和外链。
